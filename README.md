# Ray Tracing in One Weekend, in Python.
## How to run the file:
1. Open powershell or any command line in the root file
2. Run:
```powershell
.\main.py > image.ppm
```
3. open image.ppm in a viewer of choice
4. rejoice.

## Limitations
As many of you may know, the RTIOW book is written in C++. Writing this program in python, albeit slightly easier to understand, is probably gonna be alot slower.
